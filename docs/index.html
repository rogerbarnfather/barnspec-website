Two ways to do everything #

Everything in Barnspec can be done in the browser app or on the command line, and both write the same records. The app is the way for a person to write a story: it asks one plain question at a time. The command line is the way for a script, a seed file, CI or an AI agent, since it takes flags or a JSON file and never prompts. A few steps, such as running Scenarios, are command-line only because there is no judgement call to make.

The examples in these pages use a hotel, and the commands were run for real in a new folder with the released packages. A command is written vendor/bin/barnspec; the command reference shows shorter ways to type it.
